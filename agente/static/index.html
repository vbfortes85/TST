O que este protótipo cumpre (entregas do PRD §7)

  1. Ingestão — API pública do DataJud (TST e TRT1–24), paginação e rate limit.
  2. Pré-filtro estrutural — classe processual + assuntos TPU, critérios versionados em config/filtros_estruturais.json.
  3. Classificação semântica — heurística auditável que distingue “o médico prestava serviços” de “atestado médico”; camada LLM opcional.
  4. Deduplicação entre instâncias — agrupamento pelo número CNJ único, aparição canônica pelo grau mais alto.
  5. Entrega/exportação — planilha CSV (registro por acórdão, PRD §6.1) e JSONL completo.
  6. Atualização incremental — nova coleta captura apenas decisões posteriores ao último @timestamp visto.
  7. Rastreabilidade (Produto 2) — auditoria integral + geração do rascunho do Caderno Técnico a partir dos registros reais.

Etapa 1 — Coleta no DataJud (gratuita, “atacado”)

Os critérios da consulta (janela temporal desde 11/11/2017, padrões de classe e assunto) vêm de config/filtros_estruturais.json e ficam gravados na auditoria de cada sessão. Se a rede local bloquear o DataJud, o erro é registrado e exibido — nenhum dado é inventado.
